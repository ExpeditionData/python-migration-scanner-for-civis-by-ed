# Civis Python Version Search

A Flask web app and a scanner job that run inside Civis Platform.

This project is in early setup. Installation, configuration, and usage
instructions will be added as the app is built.

## Configuration

Copy `.env.example` to `.env` and fill in your own values. Never commit `.env`.
